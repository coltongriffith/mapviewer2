Cedar Ridge demonstration files

These files reproduce the geometry used by Exploration Maps' Cedar Ridge gallery examples. Aurora Ridge Minerals, Cedar Ridge, claim identifiers, collar locations and assay text are fictional demonstration data. They are not a registry extract or exploration results.

cedar-ridge-claims.geojson: 161 polygon features in WGS84 longitude/latitude (EPSG:4326).
cedar-ridge-collars.csv: 14 collars in the same coordinate system. Result is illustrative label text, not a verified assay.

Import the boundary and assign Claims; import the CSV and assign Drillholes. Styling and callouts are configured separately. For the finished layout, open https://www.explorationmaps.com/?demo=drill_plan

You may use and modify these demonstration files for learning and testing. Keep their illustrative status clear if you redistribute them.
