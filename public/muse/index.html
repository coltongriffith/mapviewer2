Why ExplorationMaps

General mapping tools expose GIS primitives. ExplorationMaps exposes mining outcomes. The agent asks for a claim map, drill-results figure or investor map; ExplorationMaps handles the mining-specific project structure, map type, styling, provenance and output.

Security

Connected-agent keys are revocable, stored only as hashes, and scoped to specific capabilities. Map creation is rate limited and idempotent. Anonymous previews cannot accept arbitrary uploaded geometry. Official-registry provenance and known data caveats travel with the generated map.
