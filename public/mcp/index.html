Universal agent connection

One mining MCP server for ChatGPT, Claude, Gemini and other agents.

ExplorationMaps exposes mining-specific outcomes instead of generic GIS primitives: search mineral claims, create claim and tenure maps, generate investor-ready property maps, and return shareable ExplorationMaps results.

https://www.explorationmaps.com/mcp/server
Muse integration Raw API OpenAPI Privacy

preview_exploration_map

Creates a registry-backed claims, investor, or infrastructure map and returns a shareable URL.

search_mineral_claims

Searches supported official mineral registries by company/holder, claim number, claim name, or bounding box.

get_mapping_capabilities

Returns supported jurisdictions, map types, overlays, search modes and styles.

Example requests

“Make a mining claim map for this company in British Columbia and show roads, towns and rail.”
“Find the mineral claims associated with this tenure number.”
“Create an investor-ready property map for this exploration company.”
“What jurisdictions can ExplorationMaps search and map?”

Client setup

ChatGPT / Codex: use the remote MCP URL above when creating a custom app or when submitting ExplorationMaps to the public app directory.

Claude: add the URL above as a custom web connector. The same endpoint is suitable for Connectors Directory review.

Gemini: register the endpoint as a remote mcp_server using Streamable HTTP in the Gemini Interactions API or supported agent surfaces.

Safety and data

Public map previews use supported public mineral registries, are rate limited, and produce expiring unlisted share links. Registry results are informational and are not legal title opinions or legal surveys. ExplorationMaps publishes a privacy policy and terms covering agent/API usage.
