# Selected-comparison PDF evidence contract

`shared/qaqcReport.js` prepares one descriptive historical comparison. It performs no reads, writes, rendering or new statistical calculations. `buildQaqcReport({kind, propertyName, snapshot, analysis, generatedAt, chartAvailability})` accepts `duplicates` or `standards`; it invokes the existing corresponding analyzer to verify that the captured analysis agrees structurally with the snapshot. Scope, refreshed status, reference-read completeness and submitted/written/selected counts must agree. This validation cannot independently prove database authorization; callers must use the existing authorized snapshot loader.

The result owns all its data as strings and plain arrays/objects. It retains no input objects, so a caller can capture it synchronously before any asynchronous import or image decoding without copying the whole snapshot. Every selected assessed and unassessed sample is sorted by submitted row and immutable ID; unselected batch rows are omitted. Validated reference details come only from the existing analysis. Requested IDs are read from each authorized selected sample; CRM candidate pins may include other elements and are explicitly not described as missing selected-element definitions. Foreign/mismatched reference text is not copied. Validated references are deduplicated by version ID in an appendix.

The adapter keeps literal raw laboratory strings, numeric censoring bounds, exact round-trip numbers, requested and validated IDs, reference source text and each primary exclusion reason. Censored stored numbers are explicitly not measurements. Submitted rows and written records remain distinct from selected/assessed/unassessed controls. Cumulative duplicate HARD summaries overlap; CRM supplied-SD categories are disjoint. No percentage is invented for a zero denominator. Historical rollback status, source filename/hash, request fingerprint, retrieval/generation times and supplied worksheet/header row are included. There is no inferred analytical date or sequence, method/certificate verification, blank threshold or consecutive-result assessment.

`chartAvailability` is keyed by `scatter`, `hard` and `crm`, with `{available,width,height}` for each synchronously captured native SVG. An expected chart missing from the capture is an error. Complete snapshots with selected controls but no assessed controls produce explicit unavailable-chart explanations and complete evidence. Zero selected controls are refused. Disagreeing CRM definitions do not produce a combined reference chart. Geometry is supplied by the renderer; the adapter does not rebuild chart data.

`layoutQaqcReport(report,{measureText})` preflights the whole report and returns `{width:792,height:612,pages:[{commands}]}`. Text commands are `{kind:'text',x,y,text,fontSize,bold}` with **top** y coordinates and Arial measurement; chart commands are `{kind:'chart',key,x,y,width,height}`. Body text is10pt with14pt line height, margins36pt. Charts preserve captured aspect within720×300pt. Compact property/import headers and page numbers repeat. Evidence/reference blocks that span pages repeat their immutable identity with “continued”. Literal wrapping preserves every character, including Unicode, spaces and unbroken IDs; it never parses HTML or ellipsizes text.

Bounds are5,000 selected rows and5,000 unique requested/validated reference versions,64 CRM candidate pins per sample,32,768 UTF-16 code units per field,2,097,152 cumulative text code units during capture/layout, and100 landscape-letter pages. These text limits bound local work independently of source-response size. Over-limit layout throws without returning partial pages and directs the user to complete evidence in the app; it does not suggest nonexistent QA HTML/Excel exports. The browser renderer must separately enforce the32MiB final PDF limit, cancel exports on scope/auth/lifecycle changes, render sequentially, release resources, and download only after success. Raster PDF pages are not promised to contain searchable text.

Focused tests cover the selected population beyond50 rows, historical/foreign references, raw/censored/zero evidence, CRM candidate pins and negative reference bands, mutation isolation, mismatched capture, expected-chart failures, measured literal wrapping, continued identity, and the exact100-page boundary. Browser rendering, glyph coverage, image capture and final-file limits belong to the renderer tests.
