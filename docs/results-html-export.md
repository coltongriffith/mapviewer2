Both representations include the current recipe name, saved version or unsaved status, current-assay provenance, computation limitations, incomplete-load notice when applicable, and the canonical recipe notes. All cells and interval wording come directly from tableRows; this path does not recalculate grades or mark results as approved. User-controlled text is HTML-escaped.
