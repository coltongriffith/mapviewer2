# Downloading one QA/QC comparison PDF

`Download comparison PDF` captures the selected historical duplicate or standards comparison. It includes all selected evidence, even records beyond the visible 50-row table page, with requested pins, validated reference details, raw laboratory strings, censoring bounds and exclusion reasons. Duplicate reports include both existing charts; standard reports include the supplied-reference chart. The report does not combine other groups or claim to represent a whole laboratory job, current property or complete source file.

The button synchronously freezes native SVGs and the pure adapter's owned evidence, then measures the entire report before any asynchronous import. Unselected batch records are not copied into the report. The existing PNG clone supplies reviewed chart geometry and axis padding; chart-only SVGs are kept separate from the PDF's pageable metadata. Shortened unit labels refer to the PDF scope section. The PNG exporter and its output remain unchanged.

Rendering lazily imports the existing jsPDF dependency and uses one reusable 1584×1224 canvas for landscape-letter pages. Text is drawn literally with measured Arial/fallback glyphs; HTML-looking source text is never interpreted. The resulting PDF pages are raster images and are not promised to contain searchable/selectable text. Each decoded chart image and local object URL is released immediately; the page canvas is cleared in `finally`.

Limits include the pure adapter's 100-page/text/record bounds, at most 2048 native units per captured chart dimension, 8 MiB serialized SVG per chart and a 32 MiB final PDF file. Oversize or encoding failures download nothing and leave a retryable error. The final file limit is not a JavaScript heap cap: jsPDF retains accumulated document output until completion. Representative 51-control browser fixtures produced roughly 4.2 MiB across 28 pages; a zero-assessed evidence-only version produced roughly 4.1 MiB across 24 pages before final pagination polish. Resource use is bounded structurally by page/text/chart limits, but no universal browser memory guarantee is claimed.

The rendered snapshot generation is checked before export, after lazy imports, around image decoding, after page encoding/array conversion, between pages and immediately before download. Group/auth/close/navigation changes invalidate it; a later selection cannot silently replace its data. At most one PDF runs per comparison view. A complete selection with no assessed controls still offers evidence and explanations without fabricated charts. An empty selection offers no PDF.

Verification covers complete immutable capture beyond 50 rows, literal Unicode/long reference source, exact page dimensions, first/middle/last selected IDs, zero-assessed reports, stale-generation cancellation, decode/encode failures, final-size refusal and resource cleanup. Desktop/phone tests download actual PDFs and inspect their page structure plus every rendered text command. Release verification also opens the PDFs with PyMuPDF and renders representative pages with Poppler to inspect charts, text, continued record identities and page numbering. Synthetic test PDFs are verification artifacts, not production drill data.
