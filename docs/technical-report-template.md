# Technical Report template recipe

Explicit selection of the existing `ni_43101` card coordinates the existing
`ni_43101_technical` layout with supplied project information. It retains the
editor, coordinate frame, output formats and expert metadata controls.

The recipe reuses the Property template's unambiguous supplied-title resolver.
Without an unambiguous subject or meaningful title it uses “Technical Report”,
not an inferred owner or result. Generic results subtitles are cleared; supplied
subtitles and explicit title-strip overrides remain. Existing company branding,
source notes, scientific settings, layer visibility/classification and pinned
results are preserved. No brand-kit lookup or account write occurs.

Existing title-strip code remains responsible for actual scale/projection,
missing QP/figure markers and the render-time production date. Selection never
fills or saves a QP, credentials, figure number, revision, date or approval.
This presentation template does not establish regulatory compliance.

The recipe's title strip now shares one bounded line plan between the editing
stage, read-only stage, canvas and SVG. It wraps supplied long titles/company
names and uses the supplied title font. Its enlarged strip has the same reserved
space in map framing and furniture geometry. Missing markers remain italic.
The reserved height grows for supplied title/company text on narrower portrait
frames, with a bounded maximum for extreme input. Classified legend rows include
the literal source field in default headings; explicit layer/row headings and
stable class IDs, labels and values remain intact.
Extreme text is marked with an ellipsis; the saved metadata is never shortened.
Legacy unselected layouts retain their existing 72px strip and renderers.

The selected recipe fits the legend to content plus native chrome, moves scale
and north-arrow furniture to the other corner, and reserves no absent-logo gap.
Native desktop/mobile/restore/PNG verification, browser regression coverage and
final measured builds remain necessary before publication. Existing saved maps
are not automatically migrated or restyled.
